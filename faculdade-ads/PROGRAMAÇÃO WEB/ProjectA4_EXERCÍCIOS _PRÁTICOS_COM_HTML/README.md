# ✨ Descubra seu Signo

## 📚 Sobre o projeto

Desenvolvi este projeto como parte das atividades práticas da disciplina de **Programação Web**, durante minha formação em Análise e Desenvolvimento de Sistemas (ADS).

A aplicação permite que o usuário informe sua data de nascimento e consulte seu signo do zodíaco. Para realizar essa consulta, utilizei PHP para processar as informações, XML para armazenar os dados dos signos e HTML para estruturar as páginas.

Com esse projeto, pude praticar conceitos de desenvolvimento web e trabalhar com a integração entre diferentes tecnologias.

## 🎯 Objetivos

Com o desenvolvimento desta atividade, busquei:

* Praticar a criação de páginas utilizando HTML.
* Aplicar conceitos de programação com PHP.
* Trabalhar com formulários e envio de dados pelo método POST.
* Aprender a carregar e interpretar informações armazenadas em XML.
* Desenvolver uma lógica para identificar o signo de acordo com a data de nascimento.
* Organizar os arquivos de uma aplicação web.

## ⚙️ Funcionalidades

A aplicação possui as seguintes funcionalidades:

* Recebimento da data de nascimento por meio de um formulário.
* Envio das informações para processamento em PHP.
* Leitura dos dados dos signos armazenados em um arquivo XML.
* Identificação do signo de acordo com o dia e o mês de nascimento.
* Exibição do nome, período e descrição do signo encontrado.
* Opção para retornar à página inicial.

## 🛠️ Tecnologias utilizadas

Durante o desenvolvimento, utilizei:

* **HTML5:** estruturação das páginas.
* **PHP:** processamento do formulário e identificação do signo.
* **XML:** armazenamento dos dados dos signos e suas descrições.
* **CSS3:** personalização visual da aplicação.
* **Bootstrap 5.2:** estilização e organização dos elementos da interface.

## ▶️ Como executar

Para executar o projeto localmente, utilizo um ambiente com PHP instalado.

1. Abro a pasta do projeto no Visual Studio Code.
2. Abro o terminal na pasta principal.
3. Inicializo o servidor de desenvolvimento com o comando:

```bash
php -S localhost:8000
```

4. Acesso o endereço abaixo no navegador:

```text
http://localhost:8000
```

5. Informo uma data de nascimento e clico em **Consultar** para visualizar o resultado.
