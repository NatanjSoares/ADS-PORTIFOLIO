# Gerador de Tabuada Interativo

Atividade prática de Desenvolvimento em JavaScript — U1: Princípios do JavaScript; A3: Estruturas de Repetição.

## Estrutura de arquivos

- `index.html`: estrutura e conteúdo da página.
- `css/style.css`: apresentação visual.
- `js/script.js`: validação, cálculo da tabuada e manipulação do DOM.

## Como executar

1. Extraia a pasta do projeto.
2. Abra a pasta `gerador_tabuada` no Visual Studio Code.
3. Abra o arquivo `index.html` em um navegador (ou utilize a extensão Live Server).
4. Digite um número inteiro entre 1 e 10 e clique em **Gerar tabuada**.

## Conceitos aplicados

HTML, CSS, JavaScript, variáveis, operações matemáticas, estrutura de repetição `for`, eventos e manipulação do DOM.
